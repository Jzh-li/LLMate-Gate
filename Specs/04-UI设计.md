# LLMate Gate 内嵌调试面板设计规范（L2-UI）

> **文档版本**：v1.0
> **层级**：L2（契约层 / Specification）
> **上游**：`整体技术方案.md` §5.x、`接口与数据契约规范.md` §10
> **受众**：workbuddy / 前端开发 Agent
> **核心规则**：本面板是 **Phase 1 开发期即时测试工具**，同时是 **v1 正式功能（发布保留）**。通过 `--no-debug` 可关闭，默认开启。

---

## 0. 定位与目标

### 0.1 一句话定位

**内嵌调试面板是"可观测性即产品"——它让 LLMate Gate 的每一次脱敏/还原都可视化，既是开发期的即时测试工具，也是用户排查"为什么这条没被拦"的运维面板，更是售前演示的最佳载体。**

### 0.2 为什么内置（决策记录）

| 候选方案 | 判断 | 结论 |
|---|---|---|
| 外置独立 Web 服务 | 需额外进程、端口、CORS，开发期启动成本高 | ❌ |
| Tauri 桌面 UI 复用 | Tauri 是给最终用户的壳，开发期用浏览器更轻 | ❌（Phase 2 再做） |
| **Go embed 内嵌单页 + WebSocket** | `go:embed` 打进二进制，零依赖，`go run .` 即开 | ✅ **采用** |

**关键判断**：这个面板不只是"测试工具"，而是把**可观测性**直接做成产品。Kiji 有映射审查 UI、PrivAiTe 只有日志——我们要做到"开箱即见流量"，这是产品差异化的一部分。

### 0.3 三条核心约束（不可违反）

1. **Playground 永不发请求到上游**：所有检测/替换/仿真都在本机完成，Playground 不持有上游 API Key，不发起任何出站 HTTP（除显式"发送"按钮，v2 才考虑）
2. **面板不破坏安全性**：流量详情里若含原始 PII，需明确标注 `[敏感]`；审计日志默认不含原文（沿用 `接口与数据契约规范.md` §9）
3. **发布保留，可关闭**：默认 `debug: true`，可通过 `--no-debug` 或配置 `gateway.debug: false` 关闭，关闭后 `/_debug`、`/ws/events`、`/_api/*` 全部 404

## 1. 架构

### 1.1 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 前端资源嵌入 | Go `embed.FS` | 单二进制，无外部文件依赖 |
| 实时推送 | WebSocket（`/ws/events`） | 流量事件实时推送到面板 |
| 前端框架 | **原生 JS + 轻量 Alpine.js（CDN 或 embed）** | 无需构建步骤，直接 `embed`；放弃 React/Vue 以避免构建链 |
| 样式 | 单 CSS 文件（embed） | 保持零依赖 |

> ⚠️ **约束**：不得使用需要 `npm build` 的框架。前端必须是"打开 HTML 即运行"的静态资源，由 `go:embed` 编译进二进制。

### 1.2 目录结构

```
gateway/
├── main.go                    # 注册 debug 路由（受 --no-debug 门控）
├── debug/
│   ├── handler.go             # HTTP 路由：/_debug、/_api/*、/ws/events
│   ├── hub.go                 # WebSocket 广播中心（多订阅者）
│   ├── store.go               # 流量记录内存存储（环形缓冲，默认 200 条）
│   └── embed.go               //go:embed assets/*
│   └── assets/
│       ├── index.html         # 面板入口
│       ├── app.js             # Alpine 组件 + WS 客户端
│       └── style.css
└── internal/
    └── pipeline/              # 在请求生命周期里调用 debug.Publish()
```

### 1.3 事件流集成

在 `internal/pipeline` 的关键节点调用 `debug.Publish(event)`，Hub 广播给所有 WS 订阅者：

```
请求进入 → debug.Publish(RequestReceived)
   ↓
检测完成 → debug.Publish(DetectionFinished, entities[])
   ↓
替换完成 → debug.Publish(ReplacementDone, mapping[])
   ↓
上游响应 → debug.Publish(UpstreamResponse)
   ↓
还原完成 → debug.Publish(RestoreDone, finalText)
```

**约束**：`debug.Publish` 必须 **非阻塞 + recover 保护**——面板崩溃绝不允许影响主代理流程。所有事件推送用带缓冲的 channel + 独立 goroutine。

### 2.1 Tab 1：流量（Traffic）

- 左侧：请求时间线，显示 method、path、耗时、PII 数量
- 点击任一条 → 右侧展开 5 段式详情（原始 / 检测 / 脱敏 / 映射 / 还原）
- **SSE 流式请求**特殊处理：右侧显示"流式还原"动画，逐块高亮占位符被还原的过程

### 2.2 Tab 2：Playground（核心，见 §3）

### 2.3 Tab 3：规则配置（Rules）

- 可视化开关各实体类型（姓名/手机/身份证/...）
- 切换替换策略：`placeholder` ↔ `simulate`（v1.1 启用）
- 配置不可逆类型（api_key/password → redact）
- 修改后**即时生效**（热加载，无需重启）

### 2.4 Tab 4：审计（Audit）

- 展示 `接口与数据契约规范.md` §9 的结构化审计事件
- 支持按时间/实体类型/会话筛选
- 导出按钮（PIPL / GDPR 格式，沿用 §9 格式）

## 3. Playground 设计（即时测试核心）

### 3.1 交互流程

```
用户输入文本
   ↓
选择：策略 [占位符/仿真替换] + 实体范围 [全部/自定义]
   ↓
点击 [检测] 或 [检测+替换]（纯本地，不上游）
   ↓
面板展示：
  · 检测到的实体列表（类型、值、偏移、置信度）
  · 替换预览（占位符版）
  · 仿真替换预览（v1.1，含格式校验标记 ✓/✗）
```

### 3.2 UI 布局

```
┌─────────────────────────────────────────────────────┐
│  Playground — 本地即时测试（不上游）                  │
├─────────────────────────────────────────────────────┤
│  输入文本:                                           │
│  ┌────────────────────────────────────────────────┐ │
│  │ 我叫李晓明，身份证11010519491231002X，         │ │
│  │ 手机13945188234，邮箱wang@corp.com            │ │
│  └────────────────────────────────────────────────┘ │
│                                                     │
│  策略: [占位符 ▼]    实体: [全部 ▼]                  │
│  [检测]  [检测+替换]  [检测+仿真替换]               │
│                                                     │

│  "我叫<<zh_person_name_1>>，身份证<<zh_id_card_1>>， │
```

### 3.3 关键约束

- **所有按钮都只调本地接口**（`/_api/detect`、`/_api/replace`），绝不发起出站请求
- "仿真替换"按钮在 v1 阶段**置灰并标注"v1.1 可用"**，但占位符替换可完整测试
- 输入文本**不落盘**（仅内存，刷新即清空），避免面板本身成为隐私泄漏点

## 4. 后端契约（与 `接口与数据契约规范.md` §10 一致）

### 4.1 端点清单

| 方法 | 路径 | 用途 | 是否需认证 |
|---|---|---|---|
| GET | `/_debug` | 面板 HTML（embed） | 否（受 `--no-debug` 门控） |
| WS | `/ws/events` | 流量事件实时推送 | 否 |
| GET | `/_api/traffic` | 拉取历史流量（环形缓冲） | 否 |
| DELETE | `/_api/traffic` | 清空录制 | 否 |
| POST | `/_api/detect` | **Playground**：仅检测 | 否 |
| POST | `/_api/replace` | **Playground**：检测 + 占位符替换 | 否 |
| GET | `/_api/rules` | 读取当前规则配置 | 否 |
| PUT | `/_api/rules` | 更新规则（热加载） | 否 |

> 🔒 **安全**：这些端点仅绑定 `127.0.0.1`（不暴露到 LAN）。若需远程调试，用户须显式设 `GATEWAY_DEBUG_BIND=0.0.0.0` 并自担风险。

### 4.2 WebSocket 事件类型

```go
type WSMessage struct {
    Type    string          `json:"type"`    // 见下表
    Data    json.RawMessage `json:"data"`
}

// Type 枚举
const (
    EvRequestReceived  = "request.received"
    EvDetectionDone    = "detection.done"
    EvReplacementDone  = "replacement.done"
    EvUpstreamResponse = "upstream.response"
    EvRestoreDone      = "restore.done"
    EvRuleChanged      = "rule.changed"
)
```

### 4.3 Playground 请求/响应（对齐 `接口与数据契约规范.md` §2）

```json
// POST /_api/detect
{
  "text": "我叫李晓明，手机13945188234",
  "entities": ["zh_person_name", "zh_phone"]
}
// → 200
{
  "entities": [
    {"type": "zh_person_name", "value": "李晓明", "start": 2, "end": 5, "confidence": 0.97},
    {"type": "zh_phone", "value": "13945188234", "start": 8, "end": 19, "confidence": 0.99}
  ],
  "latency_ms": 187
}
```

```json
// POST /_api/replace
{
  "text": "我叫李晓明，手机13945188234",
  "strategy": "placeholder",
  "entities": ["zh_person_name", "zh_phone"]
}
// → 200
{
  "replaced": "我叫<<zh_person_name_1>>，手机<<zh_phone_1>>",
  "mapping": [
    {"placeholder": "<<zh_person_name_1>>", "type": "zh_person_name", "value": "李晓明"},
    {"placeholder": "<<zh_phone_1>>", "type": "zh_phone", "value": "13945188234"}
  ]
}
```

> 🔒 **安全约束**：`value` 字段在面板显示时由前端打码（仅审计页需显式展开）。`/_api/replace` 返回的 `mapping` 仅在内存存活，不写入磁盘。

## 5. 验收标准（开发期 + 发布期）

### 5.1 Phase 1 开发期即时测试标准

| 编号 | 标准 | 验证方式 |
|---|---|---|
| D1 | `go run .` 后访问 `localhost:8400/_debug` 返回面板 HTML | 浏览器/curl |
| D2 | Agent 发请求后，面板在 **1s 内**显示完整 5 段详情 | 人工计时 |
| D3 | Playground 输入文本后点"检测"，**不发起任何出站请求**（用 `lsof`/`netstat` 验证） | 网络监控 |
| D4 | Playground "检测+替换"结果与 `接口与数据契约规范.md` §5 占位符协议完全一致 | 断言 |
| D5 | `--no-debug` 启动后，`/_debug`、`/ws/events`、`/_api/*` 全部 404 | curl |
| D6 | 面板崩溃（如 JS 报错）**不影响**代理正常转发（压测验证） | 故障注入 |

### 5.2 发布期标准

| 编号 | 标准 | 验证方式 |
|---|---|---|
| R1 | 单二进制 `./llmate-gate` 启动后面板可用（无外部资源） | `curl /_debug` |
| R2 | 默认开启，无需额外配置 | 首次启动即见 |
| R3 | `--no-debug` 可彻底关闭（含 WS 端点） | 端口扫描 |
| R4 | 面板不写入任何 PII 到磁盘（除显式审计导出） | `strace`/`dtrace` |
